= Infinispan Hot Rod C++17 Client Guide
:toc: left
:toclevels: 3

This guide covers the Infinispan Hot Rod C++17 client for the Hot Rod binary
protocol. The client speaks protocol 4.0/4.1, routes keys to their primary owner
(hash-aware), fails over automatically, and exposes every operation as a
`std::future`.

NOTE: The single source of truth for *what is implemented today* is
`docs/STATUS.md` in the repository root. If a chapter here describes a feature as
a stub, STATUS.md is authoritative for whether it has shipped.
